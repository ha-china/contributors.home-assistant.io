# 卡片功能（card feature）

> 卡片底部的额外控件，例如亮度滑块或吸尘器的按钮。

Source: https://www.hasscn.top/contributors/glossary/card-feature/

- In code: `features`, `hui-*-card-feature`
- Also: card features, features

功能（feature）让卡片无需打开[更多信息对话框](https://www.hasscn.top/contributors/glossary/more-info-dialog/)即可实现更多操作。卡片可以显示哪些功能取决于实体（entity）及其[支持的功能](https://www.hasscn.top/contributors/glossary/supported-features/)。

## Related terms

- [卡片（Card）](https://www.hasscn.top/contributors/glossary/card/): 仪表盘上的一个区块，用于显示或控制某些内容，例如实体（entity）、图表或天气预报。
- [支持的功能](https://www.hasscn.top/contributors/glossary/supported-features/): 实体（entity）设置的一个数字，用于表明其类型支持哪些功能，例如可以设置位置的卷帘（cover）。
