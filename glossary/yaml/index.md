# YAML

> 一种用于配置和数据的文本格式，通过缩进表示结构。Home Assistant 将其用于配置文件以及更多场景。

Source: https://www.hasscn.top/contributors/glossary/yaml/

- In code: `configuration.yaml`, `.yaml`

作为贡献者，你会在很多地方遇到 YAML：`configuration.yaml`、自动化（automation）和脚本、集成的 `services.yaml`、应用程序的配置、意图（intents）仓库中的句子，以及文档中的示例。

文档有自己的 [YAML 风格](https://www.hasscn.top/contributors/writing/reference/yaml/)，因此每个示例看起来都一致。

## Related terms

- [自动化](https://www.hasscn.top/contributors/glossary/automation/): 一种规则，当触发器发生且条件满足时执行操作，例如在日落时且家中有人时打开灯光。
- [Markdown](https://www.hasscn.top/contributors/glossary/markdown/): 一种用于写作的纯文本格式，使用 # 和 * 等符号来标记标题、列表和强调。本文档就是用它编写的。
