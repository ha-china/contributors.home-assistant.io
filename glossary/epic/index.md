# 史诗（Epic）

> home-assistant/epics 仓库中的一项较大规模工作，由可能跨越多个仓库的任务组成。

Source: https://www.hasscn.top/contributors/glossary/epic/

- In code: `home-assistant/epics`
- Also: epics

史诗（epic）列出了它将交付的内容以及完成的标志。它的任务是在实际开展工作的仓库中的议题（issue），例如 Home Assistant Core、前端或文档，这些任务作为子议题链接到该史诗。大多数史诗会交付路线图中的一个[机会（opportunity）](https://www.hasscn.top/contributors/glossary/opportunity/)，或其某个阶段。也有一些史诗是独立存在的，例如跨多个集成的清理工作。

只有 Open Home Foundation 的员工、获得授权的贡献者以及 GitHub 上 home-assistant 组织的成员才能创建史诗。任何人都可以阅读并关注它们。请参阅[从想法到发布](https://www.hasscn.top/contributors/roadmap/how-it-works/)。

## Related terms

- [机会（Opportunity）](https://www.hasscn.top/contributors/glossary/opportunity/): 路线图仓库中的一种议题，描述一个值得解决的问题、其重要性，以及为其设想的解决方案。
- [路线图](https://www.hasscn.top/contributors/glossary/roadmap/): Open Home Foundation 希望接下来在 Home Assistant 及其其他项目中解决的问题，以机会（opportunity）的形式在 OpenHomeFoundation/roadmap 仓库中跟踪。
- [Issue（议题）](https://www.hasscn.top/contributors/glossary/issue/): GitHub 上关于仓库中某个问题（如 bug）的报告，人们可以对其进行讨论和跟踪。
