# 徽章（Badge）

> 视图顶部的一个小胶囊，可一目了然地显示某个状态，例如室外温度。

Source: https://www.hasscn.top/contributors/glossary/badge/

- In code: `hui-entity-badge`, `ha-badge`
- Also: badges

徽章（badge）位于卡片上方，可以打开其实体（entity）的更多信息对话框。`ha-badge` 组件负责绘制它们，并在 UI 中其他地方用于类似的胶囊。

## Related terms

- [视图（View）](https://www.hasscn.top/contributors/glossary/view/): 仪表盘中的一个页面。其类型（如 sections、masonry 或 panel）决定了卡片的布局方式。
- [卡片（Card）](https://www.hasscn.top/contributors/glossary/card/): 仪表盘上的一个区块，用于显示或控制某些内容，例如实体（entity）、图表或天气预报。
