卷帘实体（cover entity）控制遮挡开口并可开合的物体：百叶窗、遮光帘、窗帘、遮阳篷、车库门、大门以及电动窗户。它可以报告和设置位置，以及带有叶片的百叶窗的倾斜角度。继承自 `homeassistant.components.cover` 中的 `CoverEntity`。

卷帘只能用于遮挡开口的物体。控制水或气体流动的设备应使用[阀门（valve）](/core/entities/valve/)。需要上锁和解锁的门应使用[锁（lock）](/core/entities/lock/)。对于其他任何情况，请使用其他实体（entity）类型，例如[数字（number）](/core/entities/number/)，即使在旧集成中使用的是卷帘。

有关前端如何显示卷帘，请参阅[卷帘更多信息视图](/design/more-info/cover/)。

## 属性

卷帘实体除了具有[通用实体属性](/core/entities/entity-class/)之外，还具有以下属性。每个属性都可以通过其对应的 `_attr_` 属性来设置，例如 `_attr_is_closed`。

| 名称 | 类型 | 默认值 | 描述 |
| ---- | ---- | ------- | ----------- |
| `is_closed` | `bool \| None` | Required | Whether the cover is closed. Used for the state. |
| `is_opening` | `bool \| None` | `None` | Whether the cover is opening. Used for the state. |
| `is_closing` | `bool \| None` | `None` | Whether the cover is closing. Used for the state. |
| `current_cover_position` | `int \| None` | `None` | The position, from 0 (closed) to 100 (fully open). |
| `current_cover_tilt_position` | `int \| None` | `None` | The tilt, from 0 to 100. Closed at 0 and open at 100, unless you describe it differently. See [Tilt position](#tilt-position). |
| `open_tilt_position` | `int \| None` | `None` | The tilt where the slats are open, from 0 to 100. `None` means the default. See [Tilt position](#tilt-position). |
| `closed_tilt_positions` | `list[int] \| None` | `None` | The tilts where the slats are closed: 0, 100, or both. `None` means the default. See [Tilt position](#tilt-position). |
| `tilt_start_angle` | `int \| None` | `None` | The angle of the slats at tilt 0, from -90 to 90 degrees. Set it together with `tilt_end_angle`, to a different value. |
| `tilt_end_angle` | `int \| None` | `None` | The angle of the slats at tilt 100, from -90 to 90 degrees. Set it together with `tilt_start_angle`, to a different value. |
| `device_class` | `CoverDeviceClass \| None` | `None` | What kind of cover it is. See [Device classes](#device-classes). |
| `supported_speeds` | `list[str] \| None` | `None` | The speeds the cover can move at when it opens, closes, or moves to a position. `None` or an empty list means no speed selection. Use the standard speeds `CoverSpeed.FAST`, `CoverSpeed.MEDIUM`, and `CoverSpeed.SLOW` from `homeassistant.components.cover` where they fit your device. An action without a speed moves the cover at the device's default speed. |

当您将 `supported_speeds` 设置为列表时，Home Assistant 会将其添加为 `supported_speeds` 属性，并在调用您之前检查操作中的 `speed` 是否在列表中。不在列表中的速度会被丢弃，卷帘会以默认速度移动。如果没有速度，操作中的 `speed` 会被丢弃。

## Tilt position

The tilt is a number from 0 to 100. By default, the slats are closed at 0 and open at 100. If your cover works differently, describe it with these properties:

- `open_tilt_position` is the tilt where the slats are open. Your `open_cover_tilt` moves the slats there.
- `closed_tilt_positions` holds the tilts where the slats are closed: `[0]`, `[100]`, or `[0, 100]`. Your `close_cover_tilt` moves the slats to the most closed position. With `[0, 100]`, you decide what that means: if one end blocks more light, always close there. If both ends are equally closed, you can leave slats that are known to be closed where they are, or always close to the same end. If the tilt is only assumed, because the device doesn't report it, close anyway.
- `tilt_start_angle` and `tilt_end_angle` are the angles of the slats at tilt 0 and at tilt 100, in degrees. Set both or neither.

A blind that is open in the middle of the scale, and closed at 0 and at 100:

```python
class MyBlind(CoverEntity):
    _attr_supported_features = (
        CoverEntityFeature.OPEN_TILT
        | CoverEntityFeature.CLOSE_TILT
        | CoverEntityFeature.SET_TILT_POSITION
    )
    _attr_open_tilt_position = 50
    _attr_closed_tilt_positions = [0, 100]
```

If you know how the slats turn, set the angles instead. Home Assistant then works out the positions, and code that needs the shape of the slats, like the HomeKit bridge or a drawing of the cover, can use them. A blind with slats that turn 180° is open at 50, and closed at 0 and at 100:

```python
class MyBlind(CoverEntity):
    _attr_supported_features = (
        CoverEntityFeature.OPEN_TILT
        | CoverEntityFeature.CLOSE_TILT
        | CoverEntityFeature.SET_TILT_POSITION
    )
    _attr_tilt_start_angle = -90
    _attr_tilt_end_angle = 90
```

Set the positions as well when the device is open or closed somewhere else than the angles say.

For the angles, 0° is a slat perpendicular to the cover, and -90° and 90° are a slat that lies flat. The angle changes evenly between tilt 0 and tilt 100. A negative angle means the inside edge of the slat is higher than the outside edge. For vertical slats, seen from inside, it means the inside edge is to the left of the outside edge. If you don't know how the cover is mounted, or it has no inside and outside, like a pergola roof, make the angle go up with the tilt, like -90 and 90. The angles are approximate: good enough to draw the slats, not to follow the sun.

When you only set the angles, the cover is open where the angle is closest to 0°, rounded to a whole number, and closed where the slats lie the flattest. When both ends are equally flat, both are closed positions. If the device is closed at only one end, set `closed_tilt_positions` yourself.

The positions are exact. When the slats are closed, report exactly a closed position, like 100 and not 98. If the angles give 50 but the device reports 51 when it is open, set `open_tilt_position` to 51.

When the cover supports `SET_TILT_POSITION`, Home Assistant adds the open and closed positions as state attributes, with the defaults filled in. It adds the angles when you set them. The recorder doesn't store these attributes. Change the values only when the device or its configuration changes, not with the position of the slats, and keep them while the device is unavailable. Set `supported_features` yourself, as the examples do. If Home Assistant [guesses the features](#supported-features), `SET_TILT_POSITION` and these attributes disappear whenever the tilt is unknown.

`toggle_tilt` uses the values for every cover, also one without `SET_TILT_POSITION`.

Home Assistant raises a `ValueError` when the values are invalid or contradict each other:

- Only one angle is set, an angle is not a whole number from -90 to 90, or both angles are the same.
- `open_tilt_position` is not a whole number from 0 to 100, or `closed_tilt_positions` doesn't hold 0, 100, or both.
- The open position is also a closed position, including a default. A cover that is only closed at 100 also sets `open_tilt_position`, because the default open position is 100.

Home Assistant checks the values when it writes the state of a cover that supports `SET_TILT_POSITION`, and when `toggle_tilt` runs. If the check fails while the entity is added, the entity is not added. If it fails on a later state write, the state of the entity stops updating. If it fails in `toggle_tilt`, the action fails. Check the values you read from a device before you set them.

## Device classes

从 `CoverDeviceClass` 中设置一个[设备类别（device class）](/glossary/device-class/)。它决定了图标、前端中状态的措辞，以及语音助手对卷帘的称呼。

| 值 | 描述 |
| ----- | ----------- |
| `AWNING` | 遮阳篷，例如窗户、门或露台外侧的可伸缩遮篷。 |
| `BLIND` | 百叶窗：通过展开、收拢或倾斜来遮挡开口的联动叶片，例如窗用百叶窗。 |
| `CURTAIN` | 窗帘或帷幔，通常是悬挂在窗户或门上方、可拉开和拉上的布料。 |
| `DAMPER` | 用于减少气流、声音或光线的机械风门。 |
| `DOOR` | 供人员进出某个区域的门，通常是建筑物的一部分。 |
| `GARAGE` | 车库门。 |
| `GATE` | 通向车道或其他区域的大门，位于建筑物外部，通常是围栏的一部分。 |
| `SHADE` | 遮光帘：一整块连续的材料或相连的帘布单元，通过展开或收拢来遮挡开口，例如窗用遮光帘。 |
| `SHUTTER` | 护窗板：通过向外或向内摆动或倾斜叶片来遮挡开口的联动叶片，例如窗用护窗板。 |
| `WINDOW` | 可以打开、关闭或倾斜的窗户。 |

## 支持的功能

将 `CoverEntityFeature` 标志用 `|` 组合起来，并将其设置为 `supported_features`。参见[支持的功能（supported features）](/glossary/supported-features/)。

| 值 | 描述 |
| ----- | ----------- |
| `OPEN` | 卷帘可以打开。实现 `open_cover`。 |
| `CLOSE` | 卷帘可以关闭。实现 `close_cover`。 |
| `SET_POSITION` | 卷帘可以移动到某个位置。实现 `set_cover_position`。 |
| `STOP` | 卷帘在移动过程中可以停止。实现 `stop_cover`。 |
| `OPEN_TILT` | 卷帘可以倾斜打开。实现 `open_cover_tilt`。 |
| `CLOSE_TILT` | 卷帘可以倾斜关闭。实现 `close_cover_tilt`。 |
| `STOP_TILT` | 卷帘在倾斜过程中可以停止。实现 `stop_cover_tilt`。 |
| `SET_TILT_POSITION` | 卷帘可以倾斜到某个位置。实现 `set_cover_tilt_position`。 |
| `SPEED` | 卷帘可以以不同速度移动。设置 `supported_speeds`。 |

If you do not set `supported_features` at all, Home Assistant guesses: `OPEN`, `CLOSE`, and `STOP`, plus `SET_POSITION` when the cover reports a position, all tilt features when it reports a tilt, and `SPEED` when it has speeds. The guess follows the current state, so a cover loses `SET_POSITION` and its tilt features whenever its position or tilt is unknown, for example while the device is unavailable. Set the features yourself, so they describe what the cover can do and don't change with its state.

## 方法

实现每个方法的同步或异步变体之一，不要同时实现两者。

| 方法 | 异步变体 | 功能 |
| ------ | ------------- | ------- |
| `open_cover(**kwargs: Any)` | `async_open_cover` | `OPEN` |
| `close_cover(**kwargs: Any)` | `async_close_cover` | `CLOSE` |
| `set_cover_position(**kwargs: Any)` | `async_set_cover_position` | `SET_POSITION` |
| `stop_cover(**kwargs: Any)` | `async_stop_cover` | `STOP` |
| `open_cover_tilt(**kwargs: Any)` | `async_open_cover_tilt` | `OPEN_TILT` |
| `close_cover_tilt(**kwargs: Any)` | `async_close_cover_tilt` | `CLOSE_TILT` |
| `set_cover_tilt_position(**kwargs: Any)` | `async_set_cover_tilt_position` | `SET_TILT_POSITION` |
| `stop_cover_tilt(**kwargs: Any)` | `async_stop_cover_tilt` | `STOP_TILT` |

`set_cover_position` 接收 `ATTR_POSITION`，`set_cover_tilt_position` 接收 `ATTR_TILT_POSITION`，两者的取值范围均为 0 到 100。当卷帘具有 `supported_speeds` 时，`open_cover`、`close_cover` 和 `set_cover_position` 可以接收 `ATTR_SPEED`。

Toggling is handled for you. `toggle` stops a moving cover when it supports `STOP`, opens a closed or closing cover, and closes an opening or fully open one. A cover that stopped partly open moves the other way from the last direction it reported, and closes when it never reported one. `toggle_tilt` opens the tilt when it is exactly at a closed position, and closes it otherwise, also when the tilt is unknown. See [Tilt position](#tilt-position).

## 状态

状态由 `is_opening`、`is_closing` 和 `is_closed` 按此顺序确定，为一个 `CoverState`：

| 值 | 描述 |
| ----- | ----------- |
| `CoverState.OPENING` | 卷帘正在打开。 |
| `CoverState.CLOSING` | 卷帘正在关闭。 |
| `CoverState.CLOSED` | 卷帘已关闭。 |
| `CoverState.OPEN` | 卷帘处于打开状态，可以是完全打开或部分打开。 |

当卷帘未在移动且 `is_closed` 为 `None` 时，状态为 `unknown`。

## 示例

```python
from typing import Any

from homeassistant.components.cover import (
    ATTR_POSITION,
    CoverDeviceClass,
    CoverEntity,
    CoverEntityFeature,
)


class MyBlind(CoverEntity):
    """A blind that moves to a position."""

    _attr_has_entity_name = True
    _attr_name = None
    _attr_device_class = CoverDeviceClass.BLIND
    _attr_supported_features = (
        CoverEntityFeature.OPEN
        | CoverEntityFeature.CLOSE
        | CoverEntityFeature.STOP
        | CoverEntityFeature.SET_POSITION
    )

    def __init__(self, device: MyDevice) -> None:
        """Set up the blind."""
        self._device = device
        self._attr_unique_id = device.serial

    @property
    def current_cover_position(self) -> int:
        """Return the position, 0 is closed."""
        return self._device.position

    @property
    def is_closed(self) -> bool:
        """Return if the blind is closed."""
        return self._device.position == 0

    async def async_open_cover(self, **kwargs: Any) -> None:
        """Open the blind."""
        await self._device.move_to(100)

    async def async_close_cover(self, **kwargs: Any) -> None:
        """Close the blind."""
        await self._device.move_to(0)

    async def async_set_cover_position(self, **kwargs: Any) -> None:
        """Move the blind to a position."""
        await self._device.move_to(kwargs[ATTR_POSITION])

    async def async_stop_cover(self, **kwargs: Any) -> None:
        """Stop the blind."""
        await self._device.stop()
```
