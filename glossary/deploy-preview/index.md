# 部署预览（Deploy Preview）

> 一个包含拉取请求（pull request）更改内容的网站临时副本，由 Netlify 构建，用于在合并之前进行检查。

Source: https://www.hasscn.top/contributors/glossary/deploy-preview/

- Also: preview

文档拉取请求（pull request）会由机器人提供一个指向其部署预览（Deploy Preview）的链接。审阅者可以使用它来以读者的视角查看更改。

## Related terms

- [拉取请求（Pull request）](https://www.hasscn.top/contributors/glossary/pull-request/): 在 GitHub 上将更改合并到代码仓库的请求，合并前会先进行审查。
- [CI](https://www.hasscn.top/contributors/glossary/ci/): 持续集成（continuous integration）：在每次拉取请求（pull request）上运行的自动化检查，例如测试、代码风格检查和类型检查。
