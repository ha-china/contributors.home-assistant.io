# 社区参考

Source: https://www.hasscn.top/contributors/community/reference/

本节中的页面用于查阅信息。如需了解如何提供帮助，请从[指南](https://www.hasscn.top/contributors/community/guides/)开始。

- [社区的聚集地](https://www.hasscn.top/contributors/community/reference/channels/)：社区交流的官方场所，以及各自的用途。
- [计划](https://www.hasscn.top/contributors/community/reference/programs/)：面向内容创作者的 Creator Network，以及面向设备制造商的 Works with Home Assistant。
- [活动与日历](https://www.hasscn.top/contributors/community/reference/events/)：即将到来的发布日期和社区同步会议，以及如何订阅日历。
