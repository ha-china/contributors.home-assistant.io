    版本发布

    Home Assistant 每月的新版本是如何诞生的，以及你可以如何帮助测试、讲解和发布它。

    Home Assistant 的新版本在每个月的第一个星期三发布。在此之前，有一周的 Beta 测试期。之后，会有每周一次的补丁版本发布修复。这一节奏多年来一直保持不变，所有贡献者都遵循它。

    本部分介绍这个周期是如何运作的，以及你可以如何提供帮助。其中大部分工作并不需要你是开发者：测试 Beta 版本、报告出现的问题、让发布说明更加清晰，这些都是任何人都能做的最有价值的事情。

    从这里开始

    • 你的第一次贡献：加入 Beta 测试，在你自己的家中测试下一个版本。
    • 版本发布如何运作：从开发到补丁版本的月度周期。

    指南

    面向所有人：

    • 发布说明与发布派对：发布说明是如何编写的，以及如何提供帮助。

    面向开发者，当你的改动会影响用户时：

    • 记录不向后兼容的改动：向用户解释发生了什么变化，以及该如何应对。
    • 弃用某些内容：移除内容是如何进行的，以及需要多长时间。
    • 将修复纳入补丁版本：修复如何进入 Beta 版本和补丁版本。

    参考

    • 版本与渠道：版本号的含义，以及 stable、beta 和 dev 渠道。
    • 谁负责什么：参与版本发布的人员。

    联系谁

    • 想测试 Beta 版本？加入 Home Assistant Discord 服务器上的 #beta 频道。
    • 在 Beta 版本中发现了 Bug？在出现问题的部分的问题跟踪器中报告。参见你的第一次贡献。
    • 发布和 Beta 测试的日期可以在活动日历中查看。
