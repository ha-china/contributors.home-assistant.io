# 蓝图（Blueprint）

> 一种自动化、脚本或模板实体，其中留有需要填写的空白，方便他人复用，例如一个运动感应灯，只需填入运动传感器和灯具即可。

Source: https://www.hasscn.top/contributors/glossary/blueprint/

- In code: `blueprint`, `!input`
- Also: blueprints

这些空白就是输入项，每个输入项都可以有一个[选择器（selector）](https://www.hasscn.top/contributors/glossary/selector/)，这样用户界面就能为它显示合适的控件。

用户通过链接导入蓝图（blueprint），例如论坛帖子或 GitHub 上的文件，而不是通过[市场（Marketplace）](https://www.hasscn.top/contributors/glossary/marketplace/)。要编写和分享蓝图，请参阅市场部分的[蓝图](https://www.hasscn.top/contributors/marketplace/guides/blueprints/)指南。

## Related terms

- [自动化](https://www.hasscn.top/contributors/glossary/automation/): 一种规则，当触发器发生且条件满足时执行操作，例如在日落时且家中有人时打开灯光。
- [脚本](https://www.hasscn.top/contributors/glossary/script/): 一组命名的动作序列，可以从自动化、仪表盘或通过语音运行。
- [选择器（Selector）](https://www.hasscn.top/contributors/glossary/selector/): 描述字段取什么类型的值，例如实体、数字或时间，以便 UI 为其显示正确的控件。
