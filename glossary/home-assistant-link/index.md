# Home Assistant Link

> Nabu Casa 提供的可选订阅服务，用于远程访问、Amazon Alexa 和 Google Assistant、在线语音处理以及在线备份。

Source: https://www.hasscn.top/contributors/glossary/home-assistant-link/

- In code: `cloud`
- Formerly: Home Assistant Cloud (old name: don't use it in new text)

[Nabu Casa](https://www.hasscn.top/contributors/glossary/nabu-casa/) 运营着 Home Assistant Link，订阅收入的大部分利润用于资助 [Open Home Foundation](https://www.hasscn.top/contributors/glossary/open-home-foundation/)。Home Assistant 没有它也能正常工作：Link 提供了一些额外功能，比如从任何地方访问你的家、无需自行配置即可连接 Alexa 和 Google Assistant、为 Assist 提供更快的语音转文字（speech-to-text）服务，以及在线存储备份的地方。

它在 2026 年 10 月之前一直被称为 Home Assistant Cloud。在 Core 中，`cloud` 集成（integration）负责连接到它，并且 UI 和该集成在某些地方仍使用旧名称。在文字中，请使用 Home Assistant Link。

## Related terms

- [Nabu Casa](https://www.hasscn.top/contributors/glossary/nabu-casa/): Open Home Foundation 的商业合作伙伴，也是 Home Assistant 产品和服务（如 Home Assistant Link）的官方提供方。
- [Open Home Foundation](https://www.hasscn.top/contributors/glossary/open-home-foundation/): 拥有 Home Assistant 及许多相关项目的非营利组织，致力于智能家居中的隐私、选择权和可持续性。
