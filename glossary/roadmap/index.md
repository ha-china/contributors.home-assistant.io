# 路线图

> Open Home Foundation 希望接下来在 Home Assistant 及其其他项目中解决的问题，以机会（opportunity）的形式在 OpenHomeFoundation/roadmap 仓库中跟踪。

Source: https://www.hasscn.top/contributors/glossary/roadmap/

- In code: `OpenHomeFoundation/roadmap`
- Also: roadmap repository

路线图不是一份带有日期的功能列表。它是一组[机会](https://www.hasscn.top/contributors/glossary/opportunity/)，每个机会都是一个值得解决的问题，由基金会的产品团队管理。来自社区的功能请求会汇入其中，并且每个机会都关联到基金会的某个目标。参见[从想法到发布](https://www.hasscn.top/contributors/roadmap/how-it-works/)。

## Related terms

- [机会（Opportunity）](https://www.hasscn.top/contributors/glossary/opportunity/): 路线图仓库中的一种议题，描述一个值得解决的问题、其重要性，以及为其设想的解决方案。
- [史诗（Epic）](https://www.hasscn.top/contributors/glossary/epic/): home-assistant/epics 仓库中的一项较大规模工作，由可能跨越多个仓库的任务组成。
- [Open Home Foundation](https://www.hasscn.top/contributors/glossary/open-home-foundation/): 拥有 Home Assistant 及许多相关项目的非营利组织，致力于智能家居中的隐私、选择权和可持续性。
