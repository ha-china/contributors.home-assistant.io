# 发行说明

> home-assistant.io 上的博客文章，介绍某个版本中的新功能、变更内容，以及用户需要为此做些什么。

Source: https://www.hasscn.top/contributors/glossary/release-notes/

发行说明会在发布当天发布在 [Home Assistant 博客](https://www.home-assistant.io/blog/categories/core/)上。除了亮点内容之外，其中还包含针对每个补丁版本（patch release）的章节、一个介绍[不向后兼容的变更](https://www.hasscn.top/contributors/glossary/backward-incompatible-change/)的章节，以及所有变更的完整列表。

关于不向后兼容变更的文字说明来自其拉取请求（pull request）的描述。这就是为什么拉取请求模板要求你面向用户来撰写这段说明。参见[发行说明与发布派对](https://www.hasscn.top/contributors/releases/guides/release-notes/)。

## Related terms

- [发布（Release）](https://www.hasscn.top/contributors/glossary/release/): Home Assistant 的新版本。每月第一个星期三发布一个新版本，期间还会有补丁发布。
- [向后不兼容的变更](https://www.hasscn.top/contributors/glossary/backward-incompatible-change/): 一种需要用户或开发者在他们那一侧做出更改的变更，例如修改他们的配置或自定义集成。
- [补丁版本（patch release）](https://www.hasscn.top/contributors/glossary/patch-release/): 在每月版本之间发布的小型修复版本，例如 2026.10.1。
- [Beta](https://www.hasscn.top/contributors/glossary/beta/): 下一个发布版本的测试版本，在正式发布前一周发布，以便在所有人更新之前发现问题。
