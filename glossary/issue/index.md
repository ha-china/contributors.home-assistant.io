# Issue（议题）

> GitHub 上关于仓库中某个问题（如 bug）的报告，人们可以对其进行讨论和跟踪。

Source: https://www.hasscn.top/contributors/glossary/issue/

- Also: issues, GitHub issue, issue tracker

每个仓库都有自己的 issue（议题）。在 Home Assistant 中，issue 用于报告问题：例如 bug，或文档中错误的页面。功能建议请提交到[功能请求讨论区](https://github.com/orgs/home-assistant/discussions)，支持方面的问题请前往[社区论坛](https://community.home-assistant.io/)。参见[我们的交流渠道](https://www.hasscn.top/contributors/start/where-we-talk/)。

issue 与修复问题（repair issue）不同，后者是 Home Assistant 向其用户展示的。那是一种[修复（repair）](https://www.hasscn.top/contributors/glossary/repair/)。

## Related terms

- [仓库](https://www.hasscn.top/contributors/glossary/repository/): GitHub 上的一个项目：包括其文件，以及对这些文件每一次更改的完整历史记录。
- [拉取请求（Pull request）](https://www.hasscn.top/contributors/glossary/pull-request/): 在 GitHub 上将更改合并到代码仓库的请求，合并前会先进行审查。
- [修复（Repair）](https://www.hasscn.top/contributors/glossary/repair/): Home Assistant 在“修复”（Repairs）中向用户显示的问题，以及相应的处理方法，例如即将失效的配置。
