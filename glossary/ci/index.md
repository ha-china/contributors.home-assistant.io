# CI

> 持续集成（continuous integration）：在每次拉取请求（pull request）上运行的自动化检查，例如测试、代码风格检查和类型检查。

Source: https://www.hasscn.top/contributors/glossary/ci/

- In code: `GitHub Actions`
- Also: continuous integration, checks

拉取请求（pull request）只有在所有检查通过后才能被合并。大多数检查也可以在你自己的电脑上运行，因此你可以在推送之前先修复问题。

## Related terms

- [拉取请求（Pull request）](https://www.hasscn.top/contributors/glossary/pull-request/): 在 GitHub 上将更改合并到代码仓库的请求，合并前会先进行审查。
