# Markdown

> 一种用于写作的纯文本格式，使用 # 和 * 等符号来标记标题、列表和强调。本文档就是用它编写的。

Source: https://www.hasscn.top/contributors/glossary/markdown/

- In code: `.md`, `.markdown`

home-assistant.io 和本网站的页面都是 Markdown 文件，GitHub 上的描述和评论也是如此。要修改某个页面，你需要编辑它的 Markdown，通常可以直接在浏览器中进行。参见[编写文档](https://www.hasscn.top/contributors/writing/)。

## Related terms

- [YAML](https://www.hasscn.top/contributors/glossary/yaml/): 一种用于配置和数据的文本格式，通过缩进表示结构。Home Assistant 将其用于配置文件以及更多场景。
- [拉取请求（Pull request）](https://www.hasscn.top/contributors/glossary/pull-request/): 在 GitHub 上将更改合并到代码仓库的请求，合并前会先进行审查。
