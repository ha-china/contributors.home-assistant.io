# 应用参考

> 构建应用时需要查阅的详细信息。配置键、Bashio 函数、文件、运行时环境以及安全评级。

Source: https://www.hasscn.top/contributors/apps/reference/

本节中的页面用于查阅信息。如需了解原因和方法，请从[指南](https://www.hasscn.top/contributors/apps/guides/)开始。

- [应用配置](https://www.hasscn.top/contributors/apps/reference/configuration/)：`config.yaml` 的每个配置键。
- [Bashio](https://www.hasscn.top/contributors/apps/bashio/)：基础镜像中 shell 库的每个函数。
- [应用文件](https://www.hasscn.top/contributors/apps/reference/files/)：应用文件夹和仓库中的文件。
- [运行时环境](https://www.hasscn.top/contributors/apps/reference/environment/)：你的容器从 Supervisor 获得的内容：环境变量、文件夹和网络地址。
- [安全评级](https://www.hasscn.top/contributors/apps/reference/security-rating/)：Supervisor 如何计算用户看到的评级。
- [Supervisor API](https://www.hasscn.top/contributors/apps/supervisor-api/)：你的应用可以调用的端点。
