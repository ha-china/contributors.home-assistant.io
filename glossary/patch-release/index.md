# 补丁版本（patch release）

> 在每月版本之间发布的小型修复版本，例如 2026.10.1。

Source: https://www.hasscn.top/contributors/glossary/patch-release/

- Also: patch releases, patch

版本号中的最后一个数字表示补丁版本（patch release）的序号：2026.10.1 是 2026.10.0 之后的第一个补丁版本。修复内容会先合并到 `dev` 分支，然后再挑选进入下一个补丁版本。每个补丁版本在当月的发布说明中都有自己独立的章节。参见 [Get a fix into a patch release](https://www.hasscn.top/contributors/releases/guides/patch-releases/)。

## Related terms

- [发布（Release）](https://www.hasscn.top/contributors/glossary/release/): Home Assistant 的新版本。每月第一个星期三发布一个新版本，期间还会有补丁发布。
- [Beta](https://www.hasscn.top/contributors/glossary/beta/): 下一个发布版本的测试版本，在正式发布前一周发布，以便在所有人更新之前发现问题。
- [发行说明](https://www.hasscn.top/contributors/glossary/release-notes/): home-assistant.io 上的博客文章，介绍某个版本中的新功能、变更内容，以及用户需要为此做些什么。
