# 翻译指南

> 逐项讲解翻译中较难处理的部分。占位符、新语言以及可翻译的字符串。

Source: https://www.hasscn.top/contributors/translate/guides/

每篇指南涵盖一个任务。前两篇面向翻译人员，最后一篇面向为 Home Assistant 添加文本的开发者。

- [占位符和引用](https://www.hasscn.top/contributors/translate/guides/placeholders/)：字符串中不应翻译的部分，以及如何处理它们。
- [申请新语言](https://www.hasscn.top/contributors/translate/guides/new-language/)：如何让您的语言被添加。
- [让您的字符串可翻译](https://www.hasscn.top/contributors/translate/guides/developers/)：如何编写翻译人员能够处理的字符串。
