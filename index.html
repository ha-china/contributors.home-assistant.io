    你想做什么？

    Start here

    • 快速上手了解项目如何运作，以及如何完成你的第一次贡献。

    Build the software

    • 开发集成Python、核心与集成平台。
    • 开发前端仪表盘、面板与对话框。
    • 构建应用打包与 Home Assistant 协同运行的软件。
    • 分享你构建的东西发布集成、卡片、主题和蓝图，供他人安装。
    • 开发伴侣应用Android、iOS 与 macOS。
    • 开发操作系统和 Supervisor操作系统、硬件板与更新。

    Design, write, translate

    • 设计体验基础、组件、模式与界面文案。
    • 以 Home Assistant 的身份发声Home Assistant 是谁、说话是什么腔调，以及如何使用它的名称和标志。
    • 编写文档home-assistant.io 上的用户文档。
    • 做翻译把 Home Assistant 带到你的语言。

    Run the project

    • 发展社区内容审核、社交媒体与活动。
    • 测试 beta 和正式版试用 beta、报告问题，了解一个版本是如何发布的。
    • 看看我们去向何方想法如何变成计划中的工作，以及你在哪里能参与塑造接下来的一切。
    • 参加活动社区同步会与发布日，以及如何把它们加进你的日历。

    Understand how it works

    • 理解架构各部分如何衔接，以及背后的决策。
    • 守护家庭安全报告漏洞，并构建保护其所在家庭的软件。
    • 做数据工作统计分析和开放数据集。
    • 查阅术语一个术语只有一个含义。代码、界面文案与文档共用。

    初次来访？四步上手。

    1. 选择一个领域大多数领域都有各自的“首次贡献”指南。
    2. 加入讨论找到正在做这件事的人，打个招呼。
    3. 找点小事做一个适合新手的 issue、一个错别字、一处缺失的翻译。
    4. 提交成果获得反馈、迭代改进，看着它随版本发布。
