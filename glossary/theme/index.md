# 主题

> 一组 CSS 变量，用于更改前端界面的颜色及部分尺寸。

Source: https://www.hasscn.top/contributors/glossary/theme/

- In code: `themes`, `--primary-color`
- Also: themes

用户可以在自己的个人资料中选择一个主题，也可以为仪表盘（dashboard）的某个视图或卡片设置主题。主题会覆盖前端的[设计令牌（design tokens）](https://www.hasscn.top/contributors/glossary/design-token/)。

## Related terms

- [设计令牌（Design token）](https://www.hasscn.top/contributors/glossary/design-token/): 设计中一个有名称的值，例如颜色、间距或圆角，用来代替硬编码的值。
- [前端](https://www.hasscn.top/contributors/glossary/frontend/): Home Assistant 的网页界面，使用 Lit 和 TypeScript 构建，位于 home-assistant/frontend 仓库中。
