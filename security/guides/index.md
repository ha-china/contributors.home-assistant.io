# 安全指南

> 针对不同类型的贡献，如何保证你编写或审查的代码安全。

Source: https://www.hasscn.top/contributors/security/guides/

每篇指南涵盖一种贡献类型。它们建立在[Home Assistant 如何处理信任](https://www.hasscn.top/contributors/security/how-it-works/)的基础上，如果你还没有读过，请先阅读那篇文档。

- [安全的集成（integration）](https://www.hasscn.top/contributors/security/guides/integrations/)：凭据、证书、脱敏、仅管理员访问、webhook 和文件路径。
- [前端中的不可信内容](https://www.hasscn.top/contributors/security/guides/frontend/)：转义、净化和安全链接。
- [安全的应用](https://www.hasscn.top/contributors/security/guides/apps/)：关于应用和 Supervisor 的安全公告带来的启示。
- [安全的伴侣应用（companion apps）](https://www.hasscn.top/contributors/security/guides/companion-apps/)：链接、导出的组件、WebView 和 JavaScript 桥接。
- [依赖项与供应链](https://www.hasscn.top/contributors/security/guides/dependencies/)：Home Assistant 对一个库有哪些要求，以及如何进行检查。
- [带着安全意识进行审查](https://www.hasscn.top/contributors/security/guides/reviewing/)：在拉取请求（pull request）中应该关注什么，以及发现问题后该怎么做。
