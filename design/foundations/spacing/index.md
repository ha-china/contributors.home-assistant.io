# 间距

> Home Assistant 界面的间距比例和圆角半径。

Source: https://www.hasscn.top/contributors/design/foundations/spacing/

一致的间距能让界面显得平静且易于浏览。Home Assistant 使用以 4 像素为步长的间距比例。

## 间距比例

使用这些设计令牌（token）来设置内边距、外边距和间隙。较小的步长用于组件内部的空间，较大的步长用于组件之间的空间。

- `--ha-space-1`: 4px
- `--ha-space-2`: 8px
- `--ha-space-3`: 12px
- `--ha-space-4`: 16px
- `--ha-space-5`: 20px
- `--ha-space-6`: 24px
- `--ha-space-7`: 28px
- `--ha-space-8`: 32px
- `--ha-space-9`: 36px
- `--ha-space-10`: 40px
- `--ha-space-11`: 44px
- `--ha-space-12`: 48px
- `--ha-space-13`: 52px
- `--ha-space-14`: 56px
- `--ha-space-15`: 60px
- `--ha-space-16`: 64px
- `--ha-space-17`: 68px
- `--ha-space-18`: 72px
- `--ha-space-19`: 76px
- `--ha-space-20`: 80px

## 圆角半径

圆角是 Home Assistant 个性的一部分。卡片和对话框采用较大的圆角，小元素的圆角则较小。按钮和标签（chip）使用药丸形状。

- `--ha-border-radius-sm`: 4px
- `--ha-border-radius-md`: 8px
- `--ha-border-radius-lg`: 12px
- `--ha-border-radius-xl`: 16px
- `--ha-border-radius-2xl`: 20px
- `--ha-border-radius-3xl`: 24px
- `--ha-border-radius-4xl`: 28px
- `--ha-border-radius-5xl`: 32px
- `--ha-border-radius-6xl`: 36px
- `--ha-border-radius-pill`: 9999px
- `--ha-border-radius-circle`: 50%
- `--ha-border-radius-square`: 0
