# 自定义卡片（Custom card）

> 不属于前端、由用户从 JavaScript 文件加载的卡片。

Source: https://www.hasscn.top/contributors/glossary/custom-card/

- In code: `custom:`, `window.customCards`
- Also: custom cards

自定义卡片（custom cards）是 Web 组件，在卡片的类型中使用 `custom:` 前缀。它们可以使用前端传递给卡片的所有内容，例如 `hass` 对象。

## Related terms

- [卡片（Card）](https://www.hasscn.top/contributors/glossary/card/): 仪表盘上的一个区块，用于显示或控制某些内容，例如实体（entity）、图表或天气预报。
- [自定义集成（custom integration）](https://www.hasscn.top/contributors/glossary/custom-integration/): 不属于 Home Assistant Core 的集成，由用户安装到 `custom_components` 文件夹中。
