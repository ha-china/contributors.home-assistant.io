# 设计令牌（Design token）

> 设计中一个有名称的值，例如颜色、间距或圆角，用来代替硬编码的值。

Source: https://www.hasscn.top/contributors/glossary/design-token/

- In code: `--ha-*`
- Also: design tokens, tokens

令牌（token）是 CSS 变量，例如 `--ha-space-4`。当所有地方都使用它们时，设计只需在一处修改即可生效，主题也可以覆盖它们。

## Related terms

- [主题](https://www.hasscn.top/contributors/glossary/theme/): 一组 CSS 变量，用于更改前端界面的颜色及部分尺寸。
- [前端](https://www.hasscn.top/contributors/glossary/frontend/): Home Assistant 的网页界面，使用 Lit 和 TypeScript 构建，位于 home-assistant/frontend 仓库中。
