# 更多信息对话框

> 当你选择一个实体（entity）时打开的对话框，包含其控件、历史记录和设置。

Source: https://www.hasscn.top/contributors/glossary/more-info-dialog/

- In code: `ha-more-info-dialog`, `more-info-<domain>`
- Also: more-info, more info

每种实体类型在其中都有自己的控件：灯的亮度滑块、气候设备的恒温器。当卡片不够用时，用户就会转到更多信息对话框。

## Related terms

- [卡片（Card）](https://www.hasscn.top/contributors/glossary/card/): 仪表盘上的一个区块，用于显示或控制某些内容，例如实体（entity）、图表或天气预报。
- [实体（Entity）](https://www.hasscn.top/contributors/glossary/entity/): Home Assistant 可以显示、测量或控制的一个事物，例如灯、温度传感器或开关。每个实体都有一个状态。
