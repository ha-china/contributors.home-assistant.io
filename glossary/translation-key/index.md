# 翻译键（translation key）

> 指向集成（integration）的 `strings.json` 中某段文本的键，以便该文本可以被翻译。集成使用键，而不是代码中的英文文本。

Source: https://www.hasscn.top/contributors/glossary/translation-key/

- In code: `translation_key`, `strings.json`
- Also: translation keys, strings.json

实体（entity）名称、状态、配置流程步骤、错误和异常都来自 `strings.json`。其中的英文文本会被上传到 [Lokalise](https://www.hasscn.top/contributors/glossary/lokalise/)，由社区进行翻译。

## Related terms

- [Lokalise](https://www.hasscn.top/contributors/glossary/lokalise/): 社区翻译 Home Assistant 的平台：包括前端、集成（integration）和配套应用。
- [实体（Entity）](https://www.hasscn.top/contributors/glossary/entity/): Home Assistant 可以显示、测量或控制的一个事物，例如灯、温度传感器或开关。每个实体都有一个状态。
- [修复（Repair）](https://www.hasscn.top/contributors/glossary/repair/): Home Assistant 在“修复”（Repairs）中向用户显示的问题，以及相应的处理方法，例如即将失效的配置。
