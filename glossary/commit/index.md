# 提交（Commit）

> 对仓库中一个或多个文件的一次已保存的更改，并附带一条说明更改内容的消息。

Source: https://www.hasscn.top/contributors/glossary/commit/

- In code: `SHA`
- Also: commits, commit message

Git 会记录每次提交（commit）的作者和时间，并为其分配一个唯一的 ID，即 SHA 或哈希值。拉取请求（pull request）是某个分支（branch）上的一组提交。向该分支添加提交会更新对应的拉取请求。

## Related terms

- [分支（Branch）](https://www.hasscn.top/contributors/glossary/branch/): 仓库中一条独立的更改线，让你可以在不影响主版本的情况下进行开发。
- [拉取请求（Pull request）](https://www.hasscn.top/contributors/glossary/pull-request/): 在 GitHub 上将更改合并到代码仓库的请求，合并前会先进行审查。
