# 模板

> 一段 Jinja2 代码片段，根据状态计算出某个值，例如几个传感器的平均温度。

Source: https://www.hasscn.top/contributors/glossary/template/

- In code: `Template`, `cv.template`
- Also: templates, templating, Jinja

模板（template）可以在很多地方使用：自动化、脚本、通知以及模板实体。当它们所使用的状态发生变化时，模板会随之更新。

## Related terms

- [状态](https://www.hasscn.top/contributors/glossary/state/): 实体（entity）的当前值，例如 `on`、`21.5` 或 `playing`，连同其属性一起。
- [辅助元素（Helper）](https://www.hasscn.top/contributors/glossary/helper/): 用户在 UI 中创建的一种实体（entity），用于保存某个值或组合其他实体，例如开关、数字、计时器或分组。
