# 仓库

> GitHub 上的一个项目：包括其文件，以及对这些文件每一次更改的完整历史记录。

Source: https://www.hasscn.top/contributors/glossary/repository/

- Also: repositories, repo

可以把仓库（repository）想象成一个带有记忆的项目文件夹。Home Assistant 的每个部分都有自己的仓库：Home Assistant Core 位于 `home-assistant/core`，文档位于 `home-assistant/home-assistant.io`，界面位于 `home-assistant/frontend`。每个仓库都有自己的议题（issue）、拉取请求（pull request）和维护者。

刚接触 GitHub？[Use GitHub, without being a developer](https://www.hasscn.top/contributors/start/github/) 解释了你在那里会遇到的各种术语。

## Related terms

- [Fork（分叉）](https://www.hasscn.top/contributors/glossary/fork/): 你自己在 GitHub 账户上的仓库副本，你在其中进行修改，然后再提交修改建议。
- [分支（Branch）](https://www.hasscn.top/contributors/glossary/branch/): 仓库中一条独立的更改线，让你可以在不影响主版本的情况下进行开发。
- [Issue（议题）](https://www.hasscn.top/contributors/glossary/issue/): GitHub 上关于仓库中某个问题（如 bug）的报告，人们可以对其进行讨论和跟踪。
- [拉取请求（Pull request）](https://www.hasscn.top/contributors/glossary/pull-request/): 在 GitHub 上将更改合并到代码仓库的请求，合并前会先进行审查。
