# 功能请求

> 关于 Home Assistant 新功能的想法，发布在 GitHub 的功能请求讨论区，其他人可以在那里评论和投票。

Source: https://www.hasscn.top/contributors/glossary/feature-request/

- In code: `home-assistant/feature-requests`
- Also: feature requests

功能请求应提交到[功能请求讨论区](https://github.com/orgs/home-assistant/discussions)，而不是提交到代码仓库的 issue：issue 用于报告问题。[Open Home Foundation](https://www.hasscn.top/contributors/glossary/open-home-foundation/) 的产品团队会关注这些请求，并将其中一些转化为[路线图机会](https://www.hasscn.top/contributors/glossary/opportunity/)。

## Related terms

- [Issue（议题）](https://www.hasscn.top/contributors/glossary/issue/): GitHub 上关于仓库中某个问题（如 bug）的报告，人们可以对其进行讨论和跟踪。
- [路线图](https://www.hasscn.top/contributors/glossary/roadmap/): Open Home Foundation 希望接下来在 Home Assistant 及其其他项目中解决的问题，以机会（opportunity）的形式在 OpenHomeFoundation/roadmap 仓库中跟踪。
- [机会（Opportunity）](https://www.hasscn.top/contributors/glossary/opportunity/): 路线图仓库中的一种议题，描述一个值得解决的问题、其重要性，以及为其设想的解决方案。
